personal-health is a personal project for accessing the account owner's Fitbit data through the Google Health API, with their explicit permission.

Early development

Understand your history

Bring together available sleep, activity, workouts and health measurements to explore changes over time.

Choose your access

Google asks the account owner to approve specific categories. The project requests read-only access.

Run it yourself

The repository provides a Python MCP server for local or private self-hosted use, with separate authorization for each user.

What the connection requests

Activity and fitness, health metrics and measurements, sleep, profile information, account settings, nutrition and hydration logs, and GPS routes recorded during exercise. Availability depends on the account, device and API.

You control the connection

Access requires signing in to Google and granting permission. It can be revoked in Google Account settings. If you connect an AI assistant, the data you request may be shared with that assistant and its configured provider; review the privacy policy before doing so.

This is the project's public information website. It does not connect to Fitbit, collect health records or accept OAuth secrets. The MCP software runs separately on a private installation; this website does not host it.
